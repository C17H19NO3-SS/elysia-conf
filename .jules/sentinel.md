## 2023-10-27 - [Prototype Pollution via Lexer Parser]
**Vulnerability:** Prototype pollution vector found in `src/lib/parser.ts` where arbitrary keys parsed from the configuration format (like `__proto__`, `constructor`, `prototype`) could be assigned directly to object structures (`config` or `currentBlock`).
**Learning:** Because the parser maps configuration keys to Javascript object properties natively without sanitization, malicious blocks or assignments allow attackers to pollute the global Object prototype context across the Node/Bun environment.
**Prevention:** Explicit validation must be enforced on all dynamic key variables fetched from token streams before they are used as object properties to ensure they are not reserved Javascript metaproperties.

## 2024-05-15 - Path Traversal Vulnerability in File Configuration (Including Static Router)
**Vulnerability:** The custom configuration parser allowed defining dynamic file paths (`static.dir`, `logger.file`, `errors[404]`) without any path sanitization or validation. These paths were directly passed into Bun's file system methods or Elysia's static plugin (`@elysiajs/static`), enabling a malicious configuration to read or write arbitrary files on the server using directory traversal payload sequences (e.g., `../../../etc/passwd`).
**Learning:** Path parameters that originate from dynamically parsed configuration files can never be blindly trusted, especially when defining core directories like the static asset router. Even if the configuration acts as an "internal" source of truth, it can still serve as a vector for malicious payloads if untrusted operators or systems can alter it.
**Prevention:** Implement a standard strict path sanitization module that utilizes `path.normalize()` to strip out traversal artifacts and explicitly binds any generated system file paths to a constrained execution directory (`process.cwd()`) using `path.join()`. In addition, verify that the ultimately resolved path begins strictly within the intended bounding directory scope by checking if it `.startsWith(baseDir + sep)`.
